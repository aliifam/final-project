\section{Perlaatan dan Kakas}

Peralatan dan kakas yang digunakan dalam pengembangan aplikasi AtleTiket dan proyek akhir ini adalah sebagai berikut:

\subsection{Perangkat Lunak}

\begin{enumerate}
    \item Visual Studio Code: Editor kode sumber yang digunakan untuk menulis kode program.
    \item Node.js: Platform JavaScript runtime yang digunakan untuk menjalankan kode program.
    \item NPM: Manajer paket Node.js yang digunakan untuk mengelola dependensi proyek.
    \item React: Library JavaScript yang digunakan untuk membangun antarmuka pengguna.
    \item Vue :Library JavaScript yang digunakan untuk membangun antarmuka pengguna.
    \item TypeScript: Bahasa pemrograman yang digunakan untuk menulis kode program.
    \item Tailwind CSS: Framework CSS yang digunakan untuk mendesain antarmuka pengguna.
    \item GitHub: Platform pengembangan perangkat lunak yang digunakan untuk mengelola kode sumber.
    \item Figma: Aplikasi desain grafis yang digunakan untuk mendesain antarmuka pengguna dan membuat diagram alur.
    \item Hoppscotch: Aplikasi pengujian API yang digunakan untuk menguji dan mendokumentasikan API.
    \item PostgreSQL: Sistem manajemen basis data relasional yang digunakan untuk menyimpan data aplikasi.
    \item K6: Platform pengujian beban yang digunakan untuk menguji performa aplikasi.
    \item Nginx: Server web yang digunakan untuk menyajikan aplikasi.
    \item Latex: Bahasa markup yang digunakan untuk menulis dokumen proyek akhir.
    \item Excalidraw: Aplikasi web open-source yang digunakan untuk membuat diagram.
    \item Draw.io (VSCode Extension): Ekstensi Visual Studio Code yang digunakan untuk membuat diagram alur.
\end{enumerate}
