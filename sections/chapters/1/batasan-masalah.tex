\section{Batasan Masalah}
Karena keterbatasan waktu dan sumber daya, Tamu.id memiliki beberapa batasan masalah yang perlu diperhatikan, yaitu:
\begin{enumerate}
    \item Aplikasi hanya dapat diakses pada web browser dan membutuhkan jaringan internet.
    \item Pengguna tidak dapat melakukan pemesanan tanpa login ke dalam sistem.
    \item Pengguna tidak dapat melakukan pemesanan lebih dari satu jenis Pod dalam satu waktu dengan pemesanan via Platform Tamu.id.
    \item Integrasi Payment gateway yang digunakan adalah Midtrans dengan metode pembayran QRIS saja menimbang QRIS adalah standar QR Code yang dikeluarkan oleh Bank Indonesia dan hampir semua bank dan e-wallet di Indonesia sudah mendukung QRIS.
    \item Karena keterbatasan dokumen perizinan dan waktu belum ada integrasi API otomatis via webhook dengan online travel agent (OTA) seperti Traveloka, Agoda, dan Booking.com.
    \item Integrasi API Backend dengan IoT diilustrasikan dengan menggunakan aplikasi web simulasi.
\end{enumerate}
