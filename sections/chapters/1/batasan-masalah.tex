\section{Batasan Masalah}
Karena keterbatasan waktu dan sumber daya, Tamu.id memiliki beberapa batasan masalah yang perlu diperhatikan, yaitu:
\begin{enumerate}
    \item Sistem hanya dapat digunakan oleh pengguna yang telah login ke dalam sistem.
    \item Aplikasi hanya dapat diakses pada web browser dan membutuhkan jaringan internet.
    \item Tidak ada fitur multi ticket booking, yaitu pengguna hanya dapat memesan satu tiket dalam satu kali transaksi.
    \item Semua aset deskripsi penunjang event bersifat gambar seperti poster, logo, course map, ukuran kaos, dan lain-lain.
    \item Integrasi Payment gateway yang digunakan adalah Midtrans dengan metode pembayran QRIS.
    \item Belum ada integrasi API otomatis via webhook dengan online travel agent (OTA) seperti Traveloka, Agoda, dan Booking.com.
\end{enumerate}
