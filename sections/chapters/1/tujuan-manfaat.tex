\section{Tujuan dan Manfaat Proyek Akhir}

Tujuan dari proyek akhir ini sesuai dengan uruaidan pada latar belakang, rumusan, serta penyelesaian maasalah adalah:

\begin{enumerate}
    \item Mengimplementasikan passwordless authentication menggunakan OAuth Google pada aplikasi e-ticketing dengan mengimplementasikan protokol OAuth 2.0 dan JSON Web Token (JWT) sebagai mekanisme autentikasi dan otorisasi sehingga memungkinkan pengguna untuk login tanpa menggunakan kata sandi.
    \item Mengintegrasikan webhook untuk multi-channel pembayaran pada aplikasi e-ticketing dengan 3rd party payment gateway Tripay sehingga memungkinkan pembeli tiket untuk melakukan pembayaran dengan berbagai metode pembayaran.
    \item Membuat aplikasi e-ticketing AtleTiket ini berbeda dengan aplikasi e-ticketing yang sudah ada di pasaran dan apa keunggulan yang dimiliki oleh AtleTiket terutama dalam konteks penyelenggaraan event lari.
\end{enumerate}
