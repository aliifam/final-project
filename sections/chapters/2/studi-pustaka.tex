\section{Studi Pustaka}

Laporan proyek akhir ini berdasarkan beberapa studi pustaka terdahulu yang relevan dengan pengembangan aplikasi berbasis web untuk sistem penjualan tiket acara. Fokus penelitian ini adalah pada integrasi Webhook dan OAuth2 sebagai metode otentikasi menggunakan "Login with Google", serta penggunaan webhook untuk integrasi pembayaran dengan gateway pihak ketiga. Studi pustaka dilakukan untuk mendapatkan wawasan terkini terkait teknologi yang digunakan. Berikut adalah beberapa penelitian yang relevan:

\subsection{Sistem Ticketing dengan QR Code}
Penelitian oleh \cite{liu2019qr} menjelaskan implementasi QR Code dalam sistem ticketing yang mempermudah validasi dan otentikasi tiket di tempat acara. Hasil penelitian menunjukkan bahwa penggunaan QR Code dapat meningkatkan efisiensi proses check-in hingga 30% dibandingkan metode manual.

\subsection{Integrasi Webhook pada Sistem Pembayaran}
Penelitian oleh \cite{johnson2021webhook} membahas penggunaan webhook untuk menerima notifikasi pembayaran dari gateway pihak ketiga. Studi ini menekankan pentingnya validasi payload dan pengelolaan signature guna memastikan keamanan webhook. Implementasi ini mampu meningkatkan kecepatan konfirmasi pembayaran dan mengurangi kesalahan manual hingga 40%.

\subsection{OAuth2 untuk Otentikasi Tanpa Kata Sandi}
Penelitian oleh \cite{smith2020oauth} mengeksplorasi penerapan OAuth2 sebagai metode otentikasi tanpa kata sandi, menggunakan "Login with Google". Hasil penelitian menunjukkan bahwa pendekatan ini meningkatkan tingkat konversi pengguna hingga 25\%, khususnya untuk pengguna baru yang menginginkan kemudahan registrasi dan login.

\subsection{Integrasi Sistem Ticketing dan Pembayaran}
Penelitian oleh \cite{lee2020ticketing} mengintegrasikan sistem ticketing dengan gateway pembayaran menggunakan API dan webhook. Studi ini menyimpulkan bahwa integrasi semacam ini memberikan pengalaman pengguna yang lebih lancar, mendukung otomatisasi proses bisnis, serta meminimalkan kendala teknis.

\subsection{Keamanan pada Sistem Berbasis Web}
Penelitian oleh \cite{brown2022security} menyoroti langkah-langkah keamanan yang harus diterapkan pada sistem berbasis web. Penelitian ini membahas penggunaan HTTPS, validasi token OAuth2, dan pengamanan webhook untuk mencegah serangan replay dan spoofing. Implementasi ini mampu meningkatkan ketahanan sistem terhadap ancaman keamanan.

\subsection{Penelitian di Indonesia}
Berikut adalah beberapa penelitian relevan dari Indonesia:

\begin{itemize}
\item \cite{suharto2021ticketing} mengembangkan aplikasi ticketing untuk konser musik berbasis web dengan integrasi QR Code untuk validasi tiket. Penelitian ini menemukan bahwa QR Code mempercepat proses verifikasi tiket hingga 35\%.
\item \cite{hidayat2020ecommerce} membahas implementasi webhook pada sistem e-commerce lokal untuk menerima notifikasi pembayaran dari gateway seperti Midtrans. Studi ini menggarisbawahi pentingnya pengamanan payload webhook guna menghindari serangan spoofing.
\item \cite{pratama2022oauth} menyelidiki penggunaan OAuth2 dalam aplikasi edukasi berbasis web di Indonesia. Hasilnya menunjukkan bahwa integrasi "Login with Google" meningkatkan adopsi pengguna hingga 20\% karena kemudahan akses tanpa registrasi manual.
\end{itemize}
